Why decomposition helps Vietnamese:
  → Morphological complexity
  → Scaffolding benefit
  → Lower-resource advantage
  → Larger semantic structures (201.5 vs 169.8 nodes)

Why decomposition hurts English:
  → Simpler semantic mapping
  → Unnecessary intermediate steps
  → Format constraints reduce flexibility
  → End-to-end sufficient for straightforward structures

Decomposition patterns:
  → MTUP2 (2-step) > MTUP3A > MTUP3B > MTUP4
  → More steps ≠ better (error accumulation)
  → Optimal: structure → variables (not explicit concepts/relations)
  → Sweet spot: minimal scaffolding without over-specification

Scaling implications:
  → 7B model competitive with parameter efficiency
  → Could improve with larger models (13B, 70B)
  → Multilingual scaling should test 5-10 languages
  → Domain transfer (news, biomedical) remains open
